# Express.js SSL + NGINX Setup 🚀

This project demonstrates how to run an `Express.js` application with `HTTPS` using a **self-signed SSL certificate**, and how to configure **NGINX** to serve it as a reverse proxy.

---

## 🔧 Features

- HTTPS with self-signed SSL certificate
- Express.js backend server
- NGINX reverse proxy configuration
- Custom error handling (404 & 500)
